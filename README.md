# fullstack-learn-mobile-app

React Native (Expo) full-stack learning app: topic checklist, 30-day Python + DSA sprint, per-user progress.

## Run

```bash
cd study-native
npm install
npx expo start
```

Open in **Expo Go**, or web at the URL Metro prints.

## Repo layout

- `study-native/` — mobile app (this GitHub project)
- `doc/` — Full Stack Developer topic checklist
- `CHANDRU_30_DAY_PLAN.md` — 30-day job-switch plan
