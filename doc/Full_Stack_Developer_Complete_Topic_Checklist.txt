
Full-Stack Developer
Complete Topic-by-Topic Learning Syllabus
HTML • CSS • JavaScript • TypeScript • React • Node.js • Express • Python • Java • Spring Boot • APIs • Databases • AI • Cloud • AWS • DevOps
Purpose: a broad, structured checklist covering core concepts, practical subtopics, tooling, testing, deployment, security, and real-world engineering practices. Work through the sections in order, build small exercises, then combine the skills in projects. You do not need to master every advanced topic before building applications.
How to use this document
Mark each topic as Not started / Learning / Practiced / Confident.
For every major topic, write a short explanation in your own words and build at least one practical example.
Prioritize fundamentals, debugging, security, testing, Git, databases, and deployment—not just framework syntax.
Treat advanced and optional topics as a reference list; choose them based on the job or project.

21. Suggested Project Ladder
Beginner — Responsive personal portfolio with semantic HTML, CSS, JavaScript, accessibility and deployment.
Frontend — React task manager with routing, forms, validation, API calls, loading/error states and tests.
Backend — Express REST API with TypeScript, JWT authentication, role permissions, validation and PostgreSQL.
Java backend — Spring Boot inventory or billing API with JPA, MySQL/PostgreSQL, validation, security and tests.
Full stack — React + Spring Boot or React + Node application with authentication, dashboards, CRUD, search and file uploads.
NoSQL — MongoDB-backed catalog or booking service with aggregation, indexes and pagination.
AI — RAG-based document assistant with citations, access controls, evaluation and usage limits.
Cloud/DevOps — Containerize a full-stack app, add GitHub Actions CI/CD, deploy to AWS, configure monitoring and backups.
E-commerce — Shopify theme customization or integration using Liquid, Storefront API/GraphQL and webhooks.
