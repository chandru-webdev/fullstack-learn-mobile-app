## DSA: 50-problem fast track (from zero)

Goal by Day 30: **any Easy in 15–20 min; 40–50% of common Medium patterns with hints.**  
That is enough to not die in many startup screens. It is **not** enough for Amazon OA. Treat Amazon/Flipkart as lottery tickets until month 2–3.

### How to practice (this is the whole method)
1. Read the pattern note (5 min max).
2. Start timer. Blank file. 20 min Easy / 35 min Medium.
3. If stuck 8 min: look at **approach only**, close it, rewrite.
4. If you looked at code: **next day, same problem from memory.**
5. Write 4 lines in `dsa-patterns.md`. No copy-paste solutions.

Language for DSA: **Python**. Interviewers for AI fullstack expect it. Syntax you’ll need in week 1: list, dict, set, `for`, slicing, `heapq`, `collections.deque`, `defaultdict`. Learn syntax **on problems**, not from a Python book.

### Pattern map (do in this order)

**P1 Arrays / Hashing:** Two Sum, Contains Duplicate, Valid Anagram, Group Anagrams, Top K Frequent Elements, Product of Array Except Self, Longest Consecutive Sequence  

**P2 Two pointers:** Valid Palindrome, Two Sum II, 3Sum, Container With Most Water, Trapping Rain Water (stretch)  

**P3 Sliding window:** Best Time to Buy/Sell Stock, Longest Substring Without Repeating, Longest Repeating Character Replacement, Permutation in String, Minimum Window Substring (stretch)  

**P4 Stack:** Valid Parentheses, Min Stack, Daily Temperatures, Generate Parentheses  

**P5 Binary search:** Binary Search, Search 2D Matrix, Find Min in Rotated Sorted Array, Search in Rotated Sorted Array, Koko Eating Bananas  

**P6 Linked list:** Reverse List, Merge Two Sorted, Linked List Cycle, Reorder List, Remove Nth from End  

**P7 Trees:** Invert Binary Tree, Max Depth, Same Tree, Diameter, Level Order, Validate BST, LCA of BST  

**P8 Heap / interval:** K Closest Points, Last Stone Weight, Merge Intervals, Meeting Rooms (concept), Top K Frequent (again)  

**P9 Graphs (intro):** Number of Islands, Clone Graph, Course Schedule, Pacific Atlantic (stretch), Rotting Oranges  

**P10 1D DP only:** Climbing Stairs, House Robber, Coin Change, Longest Palindromic Substring, Word Break (stretch)

Skip entirely this month: tries as a topic, Fenwick, segment tree, greedy proofs, graph Dijkstra unless a JD names it, 2D DP tables, system design.
